# Debojyoti Biswas — Portfolio (GitHub Pages)

This is a lightweight, recruiter-friendly portfolio website ready for **GitHub Pages**.

## Deploy to `github.io`

1. Create a repository named: **<your-username>.github.io**
2. Upload **all files** from this folder to the repo root (including `index.html`).
3. Go to **Settings → Pages**
   - Source: `Deploy from a branch`
   - Branch: `main` (root)
4. Your site will be available at: `https://<your-username>.github.io/`

## Customize

- Edit text in `index.html`
- Styling in `styles.css`
- Optional contact form:
  - Create a Formspree form and replace `your_form_id` in `index.html`
